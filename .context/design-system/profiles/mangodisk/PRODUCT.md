# MangoDisk - Product Direction

## Naming status

`MangoDisk` is the current repository identity. The ByteDesk product rename is not
yet approved; do not invent or publish a replacement name from this profile.

## Purpose

The product is a Tauri 2 disk analyzer and cleanup application. Rust owns file
system access, scan orchestration, cleanup execution, safety boundaries, and
history; the frontend helps a person understand storage and make reviewed choices.

## Users and promises

Users locate large, duplicate, rebuildable, or application-associated data and
understand the reclaimable impact before any mutation. Scanning is read-only.
Deletion, cleanup, uninstall, and startup changes require explicit confirmation,
protection checks, and verifiable history.

## Voice

Plain, spatial, and safety-first. Distinguish estimated, selected, protected,
rebuildable, personal, deleted, failed, and reclaimed data precisely.
